# marp-layout-check

Marpスライドをプレビューし、レイアウト崩れ（オーバーフロー・要素の重なり）を検出して修正する。

## 実行手順

1. **プレビュー環境の準備**  
   Marpのプレビューができる状態にする（`npx @marp-team/marp-cli` でHTML/PDF出力、またはローカルサーバーでプレビューURLを開く）。
2. **視覚確認**  
   可能であればブラウザMCPで該当スライドのURLを開き、スナップショットまたはスクリーンショットで表示を確認する。ユーザーが範囲指定（例：15〜25枚目）していればその範囲を重点的に見る。
3. **崩れの検出**  
   以下をチェックする：下部が切れている、余白が極端に大きい/小さい、縦に並んだ項目が5つ以上で1カラムだと収まっていない、テキストやパネルが重なっている。
4. **修正案の適用**  
   検出したパターンに合わせて、下記の修正パターンから選んで適用する。
5. **再確認**  
   修正後、該当スライドを再度確認し、崩れが解消しているか確認する。

## よくある崩れと修正方針

### オーバーフロー（下部が切れる）

- **原因**: `gap`・`margin`・`padding` が大きすぎる。
- **修正**: `gap-4`→`gap-2`、`mt-6`→`mt-2`、`p-5`→`p-3` など、余白を小さくする。

### 縦に5項目以上が1カラムで収まらない

- **原因**: 1カラムではスライド高さに収まらない。
- **修正**: `grid-cols-1` を `grid-cols-2` に変更。最後の1つだけ残る場合は `col-span-2` で全幅にする。

### パネル内テキストのはみ出し

- **原因**: フォントサイズや行数が多すぎる。
- **修正**: `text-em-lg`→`text-em-base`、または項目を要約して行数を減らす。必要なら2カラム化。

## 前提

- Marpのビルド・プレビューがローカルで実行できること。
- ブラウザで確認する場合は、プレビュー用URLが利用できること（任意）。

## 禁止事項

- レイアウトだけを変え、スライドの意味やメッセージを変えないこと。文言の変更が必要な場合はユーザーに確認する。
