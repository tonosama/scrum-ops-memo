# marp-slide-style

Marpスライドのレイアウトと見た目を、スタイルガイドおよび定義済みパターンに沿って整形する。

## 実行手順

1. **参照ファイルの確認**  
   プロジェクトに `docs/style-guide.md` または `slides/example.md` があれば、先に読み込む。
2. **対象スライドの把握**  
   ユーザーが指定したスライド範囲（例：15〜20枚目）の内容を確認する。
3. **パターン選択**  
   `slides/example.md` がある場合は、内容に合うレイアウトパターン（タイトル・2カラム比較・パネル・統計など）を選ぶ。独自レイアウトは作らない。
4. **適用**  
   スタイルガイドのカラー・タイポグラフィに従い、選んだパターンのHTML/クラスを適用する。
5. **文体チェック**  
   タイトルにコロンを使っていないか、感嘆符・絵文字を避けているか、色がグレー基調・アクセント1〜2色に収まっているかを確認する。

## 参照ファイル（あれば使用）

| ファイル | 内容 |
|---------|------|
| `docs/style-guide.md` | カラーパレット、タイポグラフィ、パネルデザイン |
| `slides/example.md` | レイアウトパターン一覧とコード例 |

## スタイルガイドが無い場合の目安

- **カラー**: グレースケール基調。アクセントは濃紺（#1B4565）・ティール（#3E9BA4）に限定。1スライド1〜2色まで。
- **タイポグラフィ**: 見出し `text-em-2xl`、本文 `text-em-lg`、補足 `text-em-base`。数値強調は `text-em-3xl`。
- **パネル**: `bg-gray-50` / `bg-gray-100`、`rounded-xl`、`shadow-lg`。左ボーダーで区切りなら `border-l-4 border-gray-400` 等。
- **Tailwind利用時**: `tailwind.config.js` で `preflight: false` を設定する。

## よく使うパターン例

- **2カラム比較**: `grid grid-cols-2 gap-6`、左右で `bg-gray-50` / `bg-gray-100` とボーダーで対比。
- **セクション見出し**: グラデーション背景 `linear-gradient(to right, #1B4565, #3E9BA4)`、白文字。
- **数値・統計**: `grid grid-cols-3 gap-4`、中央に `text-em-3xl font-bold`、サブは `text-em-lg`。

## 禁止事項

- スタイルガイドや example にあるパターンを使わず、独自のレイアウトを一から作らない。
- 感嘆符・装飾絵文字・タイトルでのコロンを使用しない。
- `red-600` / `green-600` などの強い色で強調しない。
